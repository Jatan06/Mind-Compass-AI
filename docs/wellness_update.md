# Mind Compass AI - Wellness & Interactive Stress-Relief Upgrade Plan

## 📌 Executive Summary

This document outlines the proposal and technical design for transforming the **Wellness Library** in **Mind Compass AI** from a static countdown timer into an **interactive, engaging, stress-relieving hub**. By integrating tactile widgets, visual pacing animations, mini-games, and real-time audio-visual feedback, users can achieve immediate stress and anxiety reduction.

---

## 🏗️ Current State vs. Interactive Upgrade

| Aspect | Current Implementation | Interactive Upgrade |
| :--- | :--- | :--- |
| **Active Session View** | Static text instructions with a countdown timer | Live visual animations, interactive widgets & mini-games |
| **User Engagement** | Passive reading & listening | Active tactile tapping, typing, dragging, and visual feedback |
| **Audio Integration** | Background Tone.js soundscapes | Real-time audio cues triggered by user actions (pops, swells, chimes) |
| **Stress Reduction** | Delayed (depends on meditation discipline) | Immediate physiological & cognitive relief |

## 🛠️ Implementation & Architecture Roadmap

### Proposed Component Directory Structure
```
Frontend/src/components/wellness/
├── BreathingPacer.jsx        # Visual expanding orb breathing pacer
├── WorryShredder.jsx         # Thought input & shred/burn/launch particle effect
├── GroundingWizard.jsx       # 5-4-3-2-1 interactive step-card flow
├── BubblePopDeStresser.jsx   # Tactile bubble grid with Tone.js pop audio
├── BodyStretchGuide.jsx      # Interactive SVG body map & stretch guide
└── SoundscapeMixer.jsx       # Custom audio frequency & sound layer mixer
```

### Integration into `Wellness.jsx`
When a user launches an activity in `Wellness.jsx`, the view dynamically renders the corresponding interactive component based on `activity.category` or `activity.id`:

```jsx
// Active Session View Renderer
{selectedActivity.category === 'Breathing' && (
    <BreathingPacer activity={selectedActivity} onComplete={handleSkipTimer} />
)}
{selectedActivity.category === 'Grounding' && (
    <GroundingWizard activity={selectedActivity} onComplete={handleSkipTimer} />
)}
{selectedActivity.id === 'act-worry-pop' && (
    <BubblePopDeStresser activity={selectedActivity} onComplete={handleSkipTimer} />
)}
```
